Sweet Recipes Website

1. Project Overview

Sweet Recipes is a web application designed to help users explore and discover different dessert recipes through a simple, creative, and user-friendly interface.

Users can browse dessert recipes, search for specific recipes, and sort the displayed recipes.

2. Main Features

* Browse different dessert recipes.
* Search for recipes by name.
* Sort recipes based on selected criteria.
* Login page.
* Registration page.
* About Us page.
* Responsive design for desktop and mobile devices.

3. Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* React Router

4. Project Structure

The application is developed as a React Single Page Application (SPA), using reusable functional components and React Hooks.

Recipe information is stored locally as mock data during Milestone 1.

5. Installation and Setup

To run the project locally:

1. Clone the GitHub repository:
    git clone YOUR_GITHUB_REPOSITORY_URL
2. Navigate to the project folder:
    cd my-project
3. Install the required dependencies:
    npm install
4. Start the development server:
    npm run dev
5. Open the local URL displayed in the terminal.
